# Aljava 26

Site estatico para publicar o design system do aniversario Aljava #26 no GitHub Pages.

## Publicacao no GitHub Pages

1. Crie um repositorio no GitHub.
2. Envie estes arquivos para a raiz do repositorio.
3. No GitHub, abra `Settings` > `Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde o link do Pages ficar disponivel.

O arquivo de entrada do site e `index.html`.
